# 냉장고 관리 시스템 ERD

아래는 냉장고 데이터베이스의 테이블 구조와 관계를 나타낸 다이어그램입니다.

```mermaid
erDiagram
    users {
        INT id PK
        VARCHAR name
        VARCHAR room_number
    }

    categories {
        INT id PK
        VARCHAR category_name UK
        INT warning_days
    }

    ingredients {
        INT id PK
        VARCHAR name
        DATE expiration_date
        VARCHAR status
        INT user_id FK
        INT category_id FK
    }

    refrigerator_logs {
        INT id PK
        INT ingredient_id FK
        INT user_id FK
        VARCHAR action_type
        DATETIME logged_at
    }

    users ||--o{ ingredients : "넣는다 (ON DELETE SET NULL)"
    categories ||--o{ ingredients : "분류된다 (ON DELETE RESTRICT)"
    ingredients ||--o{ refrigerator_logs : "기록된다 (ON DELETE CASCADE)"
    users ||--o{ refrigerator_logs : "행동한다 (ON DELETE SET NULL)"
